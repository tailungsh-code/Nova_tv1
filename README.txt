NOVA TV - دليل التشغيل

الملفات: index.html و style.css و app.js و player.js و channels.json
الملف الوحيد الذي ستعدّله دائماً هو channels.json (لا تلمس الباقي).

========== 1) الرفع إلى GitHub Pages (من الهاتف) ==========
1. فك ضغط ملف ZIP على هاتفك (من تطبيق الملفات).
2. أنشئ حساباً في github.com ثم اضغط New repository، اكتب اسماً (مثل nova-tv)، اختر Public، ثم Create repository.
3. افتح المتصفح بوضع "موقع سطح المكتب" (Desktop site)، ثم في المستودع اضغط: uploading an existing file.
4. اختر الملفات الخمسة بعد فك الضغط، انتظر اكتمال الرفع، ثم Commit changes.
5. افتح Settings ثم Pages. في Source اختر Deploy from a branch، وفي Branch اختر main و /(root) ثم Save.
6. بعد 1 إلى 3 دقائق يظهر رابط موقعك أعلى صفحة Pages: https://اسم-المستخدم.github.io/nova-tv/
افتح الرابط في كروم أولاً للتأكد أنه يعمل.

========== 2) إضافته إلى AppCreator24 ==========
ملاحظة: لم أتمكن من التحقق من واجهة AppCreator24 الحالية، فقد تختلف أسماء الخيارات عمّا يلي.
1. أنشئ تطبيقاً جديداً وأضف قسماً أو صفحة من نوع Web (موقع).
2. الصق رابط GitHub Pages.
3. فعّل إن وجدت: ملء الشاشة، إخفاء شريط العنوان، تشغيل الجافاسكربت، السماح بتشغيل الفيديو داخل الصفحة.
4. الاتجاه: اتركه تلقائياً. المشغّل يطلب الوضع الأفقي عند ملء الشاشة، وإن لم يسمح WebView بذلك أدر الهاتف يدوياً.
5. إن لم يوفّر AppCreator24 خياراً مما سبق فسيعمل التطبيق لكن بدون تلك الميزة، ولن أدّعي غير ذلك.

========== 3) تعديل القنوات من الهاتف ==========
1. في GitHub افتح المستودع ثم channels.json ثم أيقونة القلم (Edit).
2. عدّل ثم اضغط Commit changes.
3. انتظر دقيقة أو اثنتين، ثم في التطبيق: الإعدادات > تحديث قائمة القنوات.
تنبيه: نقص فاصلة أو علامة اقتباس يُفسد الملف. عندها يبقي التطبيق آخر قائمة ناجحة. تحقق من الملف في jsonlint.com قبل الحفظ.

إضافة قناة: ضع هذا القالب داخل القوس [ ] الخاص بـ channels، وبين كل قناتين فاصلة:
{ "id": "ch_001", "name": "اسم القناة", "logo": "https://.../logo.png", "country": "MA", "category": "morocco", "streamUrl": "https://رابط-مصرح-به.m3u8", "backupUrl": "", "epgUrl": "", "featured": true }
- id يجب أن يكون فريداً لكل قناة.
- تغيير الشعار: غيّر قيمة logo، أو ارفع الصورة إلى المستودع واكتب مسارها مثل logos/2m.png.
- حذف قناة: احذف الكتلة كاملة من { إلى } مع الفاصلة المجاورة.
- تصنيف جديد: أضف {"id": "x", "name": "الاسم"} داخل categories ثم استعمل id في category.
- القنوات التي ليس لها رابط https صالح لا تظهر في التطبيق. روابط http تُحجب عادةً على المواقع الآمنة.

========== 4) الاختبار قبل النشر ==========
1. افتح الرابط في كروم على هاتفك وجرّب: البحث، المفضلة، التحديث، ثم وضع الطيران (يجب أن تبقى القنوات المحفوظة).
2. لاختبار المشغّل فقط يمكنك وضع بث تجريبي عام مثل https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8 ثم احذفه قبل النشر.
3. ثبّت نسخة AppCreator24 التجريبية على هاتفك وكرّر الاختبار.

========== حدود يجب معرفتها ==========
- القائمة تأتي فارغة: أضف فقط قنوات تملك حق بثها أو تبثها جهتها مجاناً وبشكل قانوني.
- DRM والقيود الجغرافية غير مدعومة ولا يتجاوزها التطبيق.
- حالة "مباشر" تظهر بعد نجاح تشغيل القناة على جهازك فقط، وقبل ذلك تظهر "لم تُفحص بعد".
- حقل epgUrl يظهر كرابط خارجي داخل المشغّل؛ لا يوجد عرض برامج داخلي.
- لوحة إدارة آمنة تحتاج خادماً وقاعدة بيانات وتسجيل دخول (مثل Supabase أو Firebase). لم تُبنَ هنا، وإدارة القنوات تتم عبر channels.json.

========== 5) إضافة القنوات من داخل التطبيق (جديد) ==========
1. اضغط زر + أعلى الشاشة لفتح صفحة "إضافة القنوات".
2. "رابط شامل": رابط قائمة M3U أو JSON فيها قنوات كثيرة، ويوزّعها التطبيق على التصنيفات حسب group-title أو category.
3. لكل تصنيف أيقونة وزر +: أضف رابط قائمة لذلك التصنيف فقط، أو اختر "قناة واحدة" واكتب اسمها ورابط بثها.
4. حذف رابط: اضغط أيقونة السلة مرتين. زر التحديث في الإعدادات يعيد قراءة كل روابطك.
تنبيهات:
- ما تضيفه هنا يُحفظ على هذا الهاتف فقط ولا يظهر لمستخدمين آخرين. لقنوات تظهر للجميع استخدم channels.json.
- بعض المواقع ترفض قراءة القائمة من المتصفح (CORS) فتظهر رسالة خطأ. روابط raw.githubusercontent.com تعمل عادةً.
- قد لا تعمل روابط البث نفسها بسبب DRM أو الحجب الجغرافي. أضف فقط ما تملك حق استخدامه.
